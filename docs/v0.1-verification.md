# v0.1 verification record

Checked on the native Windows development instance on 2026-10-11:

- `go test ./...` passes for the backend, including authentication, session revocation, rate limiting, liveness/readiness, SQLite backup/restore, fresh/existing database startup, and explicit migration failure.
- `npm run build` passes for the frontend.
- The running native server returns `200` from `/api/v1/health/ready` and serves the built page from one origin.
- The authenticated dashboard was inspected at desktop width and at a 390-pixel mobile viewport. Metrics and HomeDrive remain usable at mobile width; no horizontal overflow was observed. The temporary viewport override was reset afterward.
- HomeDrive API tests cover unauthenticated access, CSRF rejection, folder creation, upload/download, duplicate-file rejection, and path traversal rejection.

Still open for a v0.1 release: Docker image build/runtime and persistent-volume behavior on a clean Windows/WSL 2 setup. WSL 2 was not installed because the operator chose to leave Docker untested. A second-operator clean-machine walkthrough has not been done. Neither item is claimed as verified.
