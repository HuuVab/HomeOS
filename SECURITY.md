# Security Policy

## Supported versions

HomeOS is not yet released and currently has no supported production version.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in a public issue.

Until a private reporting channel is configured for the GitHub repository, contact the repository owner privately. Include the affected component, reproduction steps, likely impact, and any suggested mitigation. Avoid including real credentials or personal data.

Security advisories and private vulnerability reporting should be enabled in the GitHub repository settings before the first public release.
